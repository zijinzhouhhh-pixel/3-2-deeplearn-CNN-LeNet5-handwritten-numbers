MNIST IDX / ubyte 文件读取器

在浏览器中读取 MNIST 图片与标签文件， 查看单张 28×28 灰度图、标签及像素矩阵。 文件只在本地浏览器处理，不会上传。

1. 选择数据文件

支持未压缩 IDX3 文件，以及 .gz 压缩文件。
支持未压缩 IDX1 文件，以及 .gz 压缩文件。
请先选择一份图片文件和对应的标签文件。

0 为纯白色，1～253 逐渐加深，254 为纯黑色。 每个格子均为正方形，矩阵完整展示全部数值。

IDX 文件头说明： 图片文件 magic number = 2051（IDX3）； 标签文件 magic number = 2049（IDX1）。 图片像素按 uint8 读取，标签按 uint8 读取。
